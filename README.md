## Dataset

- **Source**: [Amazon Top 50 Bestselling Books 2009–2019](https://www.kaggle.com/datasets/sootersaalu/amazon-top-50-bestselling-books-2009-2019) (Kaggle)
- **Rows**: 550 | **Columns**: `Name`, `Author`, `User Rating`, `Reviews`, `Price`, `Year`, `Genre`
- Note: 550 rows correspond to 351 unique titles — some books stayed on the bestseller list across multiple years.

## Key Findings

**EDA**
- User ratings are heavily left-skewed (mean 4.62, min 3.3) — bestsellers rarely have low ratings.
- Price is right-skewed (median $11), with a handful of outliers up to $105.
- `Reviews` and `User Rating` are essentially uncorrelated (r ≈ -0.002) — review volume is not a proxy for quality.
- `Price` and `User Rating` show only a weak negative correlation (r ≈ -0.13).
- Both average rating and review counts trended upward from 2009 to 2019.

**K-Means Clustering** (features: `User Rating`, `Reviews`, `Price`, standardized)
- Cluster count (`k=5`) chosen using the elbow method **combined with silhouette score**: k=4 gives the highest silhouette (~0.36) but k=5 is close behind (~0.35) and yields a more detailed, still well-separated segmentation.
- Every cluster is auto-labeled from its centroid using **tiered thresholds** (mean and mean+1 std) so extreme sub-groups (e.g. a "very viral" cluster) don't collapse into the same label as a milder "popular" cluster — an earlier version had this collapsing issue.
- Price is the strongest cluster separator (a distinct "Premium" cluster at ~$50 avg); review volume separates a "Popular" cluster (~27k avg reviews); rating varies the least across clusters.
- Cluster-labeled data is exported to `data/processed/bestsellers_clustered.csv`.

See the notebooks in `notebooks/` for full analysis, plots, and cluster profiles.
